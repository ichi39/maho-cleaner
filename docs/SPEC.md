# 仕様書(ゲームデザイン)

この文書は、今の `index.html` の動きをまとめたものです。数値は、コードの中の定数と合わせています。変えたときは、この文書も直してください。

## 1. コンセプト

- **目的:** ひらがな・カタカナを全部覚えること。ただし、勉強を意識させない。
  - 覚えた文字の一覧、正解率、「ポイント」などは表示しない。
  - 難しさは裏で自動調整し、画面には出さない。
- **世界観:** 明るいヨーロッパファンタジー風の町。プレイヤーは魔女のお掃除屋さん。
- **画風:** パステル調のドット絵。物・人物・背景はドット絵で描く。文字だけは読みやすさのためにフォントで表示する。
- **文字が読めない前提で作る:** 操作や行き先は、すべて絵で分かるようにする。セリフは全部ひらがな(カタカナの物の名前だけ例外)。
- **操作:** タッチ(マウス)だけ。文字は必ずドラッグで動かす(タップでははまらない)。

## 2. 遊びの流れ

```
タイトル → (初回だけ)チュートリアル4枚
  → 自分のお店(お客さんが来る)
      ├ お客さんをタップ → 依頼を聞く → [うける / あとで / ことわる]
      │    └ うける → 片付ける部屋 → 物をタップ → 文字パズル → 物が直る
      │         → 全部直す → お礼 → お店に戻る → お客さんが支払って帰る
      ├ 右のドア → 商店街 → 片付けたお店 → 棚から買う → 箱で自分の部屋に届く
      ├ 左の矢印 → 自分の部屋(物を飾る・人形の着せかえ・届いた箱を開ける)
      └ 本 → 魔法の日記
  時計が閉店時刻になる(または4人対応する)と夜になる → 閉店 → 1日のまとめ → 朝(同じお客さんがまた来る)
```

## 3. 画面

`<section class="screen">` が画面です。`show(id)` で1つだけ表示します。画面の移動に動きを付けるときは `transit(id, kind)` を使います。

| id | 画面 | 主な内容 |
|---|---|---|
| `title` | タイトル | はじめる、買い物、音の3ボタン(BGM・効果音・声)。左下に「おとテスト」、右下に「はじめから」(どちらも薄い字) |
| `home` | 自分のお店 | お客さんの列、依頼カード、右のドア(商店街へ)、左の矢印(自分の部屋へ)、飾り(ビン・本・ランプ) |
| `room` | 片付ける部屋 | 依頼のお店の部屋。灰色の物をタップするとパズル |
| `puzzle` | 文字パズル | 上に壊れた物の絵、薄い文字のガイド、うねうね動く文字 |
| `mine` | 自分の部屋 | 人形、飾った物、おもちゃ箱、届いた箱、下に持ち物の段 |
| `shelf` | 商店街 | お店の外観が横に並ぶ(スクロール)。左端は自分のお店 |
| `shop` | お店の中 | 棚の品物、カウンターの店番、左の壁に出口のドア |

モーダル(重ねて出すウィンドウ): 依頼(`hreq`)、お礼(`clear`)、1日のまとめ(`dayEnd`)、ごほうびを選ぶ(`gift`)、箱を開ける(`unbox`)、日記(`diary`)、チュートリアル(`tut`)、おとテスト(`sndTest`)

### 画面の切り替え

| 移動 | 動き |
|---|---|
| お店 → 商店街 | 魔女が右のドアまで歩いて出る → 新しい画面が右から流れてくる |
| 商店街 → お店 | 魔女が左端の自分のお店まで歩き、ドアが開く → 左から流れてくる → 魔女がドアから入る |
| 商店街 → お店の中 | 魔女がお店の前まで歩き、ドアが開く → ドアの位置から丸く広がる |
| お店の中 → 商店街 | 丸く閉じて外へ。魔女はそのお店の前に立っている |
| お店 ↔ 自分の部屋 | 部屋へは左から、お店へは右から流れてくる |

商店街の移動は、遠くても0.6秒まで(遠いときは、魔女が先に近くまで移ってから歩く)。

## 4. 依頼とお客さん

### お客さん(`CLIENTS`、12人)
それぞれ次の設定を持ちます。
- 名前(ひらがな)と見た目(髪型・服・小物・肌の色)
- 好きなお店(`fav`)と苦手なお店(`dis`)
- 好きな色(`favC`)
- セリフ: あいさつ、頼み方、好きな店のとき、苦手な店のとき、お礼の3種類(ふつう・好きな店・苦手な店)、待っている間のひとこと(`fl`)3つ

好きな店・苦手な店によって、セリフが自然に変わります。苦手な店の依頼は、まれにしか来ません。

### 依頼の作り方(`makeRequest`)
- お店の種類(`CATS`)は9つ: ようふくやさん、おもちゃやさん、どうぶつやさん、やおやさん、たべものやさん、ほんやさん、おんがくやさん、ざっかやさん、しぜんの おみせ。
- 種類の選び方: 好きな店が約55%、苦手な店が約10%、残りはそれ以外。
- 最初の2回は必ず服屋です。6回目までは人形に着せられる物を優先します(着せかえを早く楽しめるように)。
- 直す物の数: 慣れるまでは3つ。そのあとは2〜4個(平均3)。
- 難しい言葉(4文字以上、濁点、小さい文字、「ー」)は、1件に1つまで。4個の依頼だけ2つまで。
- 直近の組み合わせとは重ならないようにします。
- 服には色が付きます(`pickColor`)。まだ直していない色を優先し、30%はお客さんの好きな色、6%は珍しい金・銀。

### 依頼を聞く(`tapClient`)
ウィンドウにお客さんの顔とセリフ、お店のアイコン、直す物のシルエットが出ます。ボタンは次の3つです。
- **うける:** 部屋へ行く
- **あとで:** 列に残る
- **ことわる:** 帰る。その日の人数にはそのまま数える

途中まで片付けた依頼は、タップするとそのまま部屋に入ります。

### お店の列
- 最大4人まで並びます。待っている人が0人なら4〜7秒、それ以外は18〜30秒ごとに次のお客さんが来ます。
- 吹き出しのひとことが順番に出ます。表示時間は「3秒+文字数×0.6秒」です。

### 支払い
片付けが終わると、次の順に進みます。
1. お客さんが**元いた位置から**カウンターまで歩く
2. コインが1枚ずつ飛ぶ
3. 「+N」と出て、上のコイン表示が跳ねる
4. 「またね!」と言ってドアから帰る

途中で別の画面へ移動したときは、支払いを済ませたことにして、もう一度は流しません(`settleHome`)。

## 5. 文字パズル(いちばん大事な部分)

- 上に壊れた物の絵が出て、文字の数に分かれた欠片が漂います。その下に、正解の文字の薄い影(ガイド)が並びます。枠や箱は描きません。
- 動かせる文字は、正解の文字に「惑わし」の文字を2〜3個足したものです。色も、うねり方(速さ・振れ幅・傾き・伸び縮み)も、文字ごとに違います。
- **必ずドラッグで動かします。** タップすると跳ねるだけで、はまりません。
- つかんでいる間は、その文字を繰り返し読み上げます(「よ、よ、よ…」)。
- 正しいガイドに近づくと、ガイドが金色に光り、文字が少し引き寄せられます。
- 離したとき:
  - 正しいガイドの近く(文字の大きさ×1.3以内)なら、吸い込まれてはまる(0.12秒)。
  - はまった瞬間に、少し跳ねる、一瞬金色になる、光の粒と輪が広がる、音が鳴る(はまるたびに音が高くなる)、上の物の欠片が飛び込む、が起きる。はまった文字はそのあと動かない。
  - 間違ったガイドの近くなら、ぶるっと震えて元の位置へ戻る。
  - それ以外は、その場に浮かぶ。
- 完成したとき:
  1. すぐにファンファーレと文字の踊りが始まる
  2. 0.4秒後に単語を読み上げる
  3. 読み上げが**終わってから**0.35秒後に部屋へ戻る(最大4.5秒まで待つ)
  4. 読み上げが終わったあとなら、タップで飛ばせる
- 初回だけ、指の絵がドラッグのやり方を見せます。

## 6. 難しさの自動調整(`allowed` / `pickItems`)

- 文字は、2回以上正しくはめると「慣れた」と数えます(`save.seen`、`knownN`)。
- 解禁の条件(慣れた文字の数が `k` 以上になると出るようになる):

| 種類 | 条件 |
|---|---|
| 「ー」を含む言葉 | k ≥ 12 |
| 濁点・半濁音を含む言葉 | k ≥ 20 |
| 小さい文字を含む言葉 | k ≥ 26 |
| カタカナ | ひらがな46字すべてに慣れてから |

- 1つの言葉に含まれる、まだ慣れていない文字は3つまで。1件の依頼全体では5つまで(序盤は7つ)。
- まだ慣れていない文字を含む言葉を優先して入れ、全部の文字に出会えるようにしています。カタカナの「ヲ」だけは、自然な言葉がないため出ません。

## 7. 物と言葉(`ITEMS`)

- 132個 + 特別な服7個。それぞれ `[言葉, 絵の種類, 絵の設定, お店の種類]` で持ちます。
- 言葉は、ふだんの書き方に合わせます。外来語はカタカナ、和語はひらがなです(例: 「ネコ」「けーき」のような書き方はしない)。
- 絵と名前が合うようにします(例: 布 → ふろしき・タオル、雪 → ゆきだるま)。
- 服(`isWear`)は人形の部位に着せます。

## 8. お金と買い物

### 入るお金
- 物を1つ直すと: 3コイン
- 依頼のお礼: 2×物の数。好きな店の依頼なら、さらに+4

### 値段(`priceOf`)
- 3 + 2×文字数。珍しい色は+5。
- 「きょうの おすすめ」は約4割引き(`priceE`、最低2)。

### 商店街
- 片付けたことのあるお店(その種類の物を1つでも直した)だけが開きます。開いていないお店はシャッターと鍵の絵です。
- 店番は、そのお店を最後に依頼したお客さんです(`save.keeper`)。記録がなければ、そのお店が好きなお客さんにします。
- 「きょうの おすすめ」が残っているお店には★が光ります。

### 品ぞろえ(`genStock`)
- 毎朝、お店ごとに4〜6個を作ります(その日の最初の来店時に作る)。
- **持っている物は並べません。** 買った物は、その日のうちに棚から消えます。
- 直したことのない物は、灰色のシルエットに「?」で並び、買えません。
- 1つだけ「きょうの おすすめ」になります。

### 買う流れ
1. 棚の品物をタップすると、店番がその品物の名前と値段を言う
2. 「かう」を押す
3. コインが店番へ飛ぶ
4. 品物がカウンターに運ばれ、箱に包まれる
5. 箱が自分の部屋の方へ飛んでいく

### 届く(`save.deliv`)
- 買った物は箱になって、自分の部屋の床に届きます。
- 箱が届いている間は、お店の左の矢印がピンクに光ります。
- 箱をタップすると大きな箱が出ます。それをタップすると開き、光の筋と一緒に中身が出ます。▶で閉じます。
- **持ち物に入るだけで**、自動で置いたり着せたりはしません。

## 9. 自分の部屋

- にんぎょう(白いねこ。32×32ドットの絵を、ちょうど2倍で出す): ドラッグで動かせて、タップすると跳ねます。
  - 体の寸法を決めて、服はその寸法から計算して描くので、どの服もずれません。外がわに1本の縁取りがあり、服の内がわは、その服の色の暗い色で縁が付きます。
  - 耳: ぼうし・ヘルメットのときは、耳が帽子のあなから出ます。かんむり・ティアラ・はなかんむり・リボンのときは、耳のあいだに乗ります。
  - かさは、いちばん手前に描きます。はねは、いちばん奥です。
- 服の段: タップで着る、もう一度タップで脱ぐ。同じ部位は1つまでで、入れ替わる。
- 飾る物の段: タップで部屋に置く(置いている物には黄色い枠)。枠のある物をもう一度タップすると、しまう。
- 置いた物はドラッグで動かせます。奥と手前の重なりも自動で付きます。
- 食べ物の段(りんごの絵): やおやさん・たべものやさんの品物のうち、コーヒーとワイン以外が入る(`FOOD`)。飾ることはできない。
  - 食べ物をタップして選ぶ(人形の横に、食べ物の絵が吹き出しで出る)→ 人形をタップすると食べる。もう一度食べ物をタップすると選びをやめる。
  - 食べた物は持ち物から**なくなる**(その物をすでに直していれば、あとでまたお店で買える)。
  - 文字は使わない(文字が読めなくても分かるように)。表情と効果で伝える。
  - 食べる動き: 食べ物が口へ飛ぶ(人形は目と口を大きく開ける)→ もぐもぐ(約1.1秒)→ 食べ物ごとのリアクション(約3.7秒)→ ありがとう(約1.7秒。全体で約7秒)。
  - リアクションは12種類。人形の目と口をその間だけ描き替える(`drawFace`)。目の大きさは、ふだんの目を最大にする(怖く見えないように)。効果は、人形の後ろの光、粒(ハート・星・水滴・かけら・湯気・雪・泡・音符・葉っぱ)、頭の上のくもやビリビリ、体の動き、音。

    | 種類 | 食べ物の例 | 表情 | 効果 |
    |---|---|---|---|
    | あまい | ケーキ・チョコ・もも | ハート目/にっこり/きらきら目、ほっぺが赤い | ハート・音符・きらっ、ピンクの光、跳ねる |
    | だいすき | ミルク・チーズ | ハート目/閉じ目、ω口 | 大きなハート・音符、ゆらゆら |
    | ほくほく | くり・かぼちゃ・おにぎり | にっこり/閉じ目 | 星・きらっ、軽く跳ねる |
    | じゅわー | みかん・すいか・ぶどう | ふつうの大きさの目、口を開ける | 食べ物の色の水滴 |
    | さくさく | りんご・にんじん・クッキー | ぱっちり目、もぐもぐ口 | かけら |
    | しゃきしゃき | サラダ・トマト | にっこり、もぐもぐ口 | 緑の星・葉っぱ |
    | すっぱい | レモン | ぎゅっと閉じた目、すぼめ口 | ぶるぶる、ビリビリ、緑の光、汗 |
    | にがい | ピーマン・なす | しょんぼり目、への字口 | どんより雲と雨、うなだれる |
    | つーん | たまねぎ・ねぎ | ぎゅっと閉じた目 | 涙、どんより雲 |
    | あつい | ラーメン・ホットケーキ | ぱっちり目、ふーふー口 | 湯気、赤い光、小刻みに跳ねる |
    | つめたい | アイス | 閉じた目、震える口 | 雪、水色の光、震える |
    | しゅわしゅわ | ソーダ | ぱっちり目/きらきら目、口を開ける | 泡、跳ねる |

  - 最後に人形がお礼をする: にっこり顔で、おじぎ・ぴょんぴょん・ふりふりのどれか(毎回ランダム)。ハートや音符が出て、ちりんと音が鳴る。
  - すっぱい・にがい・つーんなど、いやな物のあとは、お礼をしない。代わりに、顔をしかめたままぶるぶると首をふり、最後に「ふぅ」と湯気(ひと息)を出して落ち着く。
  - アイスは、「ひゃー!」と震える動き(半分の確率で最初に出る。約1秒)のあとに、ハート目・にっこりなどのおいしそうな動き(ハート・きらっ・体をゆらす)が続く。残り半分は、すぐおいしそうな動きになる。
  - **毎回少し変わる:** 表情(3通りから選ぶ)、動きの大きさ・向き・速さ、粒の種類と色・出る間隔、音の高さが、食べるたびにランダムに変わる(`startEat`)。
- おもちゃ箱(右下): 置いた物を引っぱって箱の上で離すと、しまえます。
  - ドラッグ中は箱がうっすら光る。近づくと、ふたが開いて点滅する。
- 物の名前は読み上げません(絵で分かるため)。

## 10. 1日の流れ(`save.day`)

- **時計(`CLK`, `D.min`):** 朝9時から始まり、画面左上にデジタル時計と、対応した人数の丸(最大4個)を出す。
  - 何もしなくても、25秒ごとに30分進む(お店の画面にいて、ウィンドウが開いていないときだけ)。
  - お客さんを1人対応する(支払いか断る)と、1時間進む。
  - 閉店時刻: 1日目は15時、2日目以降は19時。4人で閉店になったときは、時計が閉店時刻まで一気に進み、窓の太陽もそれに合わせて沈む。
  - 1日に対応できるのは最大4人。4人になるか閉店時刻になると夜になる。
  - 時計の数字は、30分ずつ「カチッ」と音を立てて進む。
- 「対応した」は、支払いを受けたか、断ったかのどちらか。「あとで」は数えません。閉店時に並んでいたお客さんは、朝にまた並びます。
- 時計の進み具合(朝9時〜閉店時刻)に合わせて、窓の外が変わります。
  - 窓の外の景色(町並み・空)は、お店・片付ける部屋・お店の中・自分の部屋で同じ(`makeBg` が同じ町並みを描き、`drawSky` が時刻に合わせて太陽・夕焼け・夜を重ねる)。商店街の空の色も同じ時刻に合わせる。
  - 太陽が動く
  - 後半は夕焼けの色になる
  - 全員を対応すると夜になる(星・月・町の明かりが出て、ランプが自動でつく)
- 最後のお客さんが帰ると、夜に向かってゆっくり暗くなります(約3秒。`H.nk` が0→1)。
  1. 魔女が「ひが くれて きたね…」と言う(窓の太陽が沈み、月と星が出てくる)
  2. 約1.8秒後にランプがともる
  3. 約2.7秒後に魔女が閉店を促す
  4. 約3秒後に「おみせを しめる」ボタンがふわっと出る
- 「おみせを しめる」を押すと、ドアのベルが鳴って魔女が「おつかれさま」と言い、約1.5秒後に1日のまとめが出ます。
  - 1日のまとめ: 来たお客さん、もらったお金、直した物、スタンプ、お店の星
  - スタンプは、まとめが出て約0.9秒後に「ポン」と押されます(直前までは前の日の数を見せる)。
- 「あさに する」で次の日になります。
  - 夜の画面から約2.8秒かけて朝になる(太陽が昇る、星と月が消える、ランプが消える)。
  - 約1.9秒後にドアが開いてベルが鳴り、「☀ Nにちめ」の文字が出る。魔女が「おはよう」と言い、そのあとお客さんが来る。
  - 前の日のお客さんのうち最大3人が「また きたよ!」と来る
  - 残っていた「あとで」のお客さんも、朝にまた並ぶ

## 11. 小さなゴール

- **スタンプカード:** 1日を閉めるたびに、はなまるを1つ押します。
  - 5つ並んだ丸の右に、ごほうびの「🎁」を置く。「あと N かいで ごほうび!」と出す。
  - 5つたまると 🎁 が跳ねて光り、ボタンが「🎁 ごほうびを もらう」に変わる。
  - 5つたまると、特別な服7種類から、持っていない物を3つ並べて1つ選べる(ほしのティアラ、にじいろドレス、ようせいのはね、はなかんむり、まほうのつえ、ガラスのくつ、ほしぞらマント)。
  - 全部持っていると、金・銀の色違いになる。
- **お店の星:** 支払いを受けたお客さんの合計人数で増えます(4・10・18・28人で星2〜5)。上のコインの横と1日のまとめに、次の星までのゲージを出す。
  - 星が増えるたびに、お店の飾りが増える(花の鉢 → 額縁 → 吊るした星 → 金のじゅうたん)。
  - 表示は、上のコインの横に小さく出すだけ。
- **まほうの みち(ステージ):** 1日のまとめに、7つの旗が並ぶ道を出す。文字の数や名前は出さず、魔女が道を進む。
  - 慣れた文字の数で進む: ひらがな 10・23・36・46字、カタカナ 15・30・44字(`STAGES`)。
  - 旗に着くと、まとめで旗がはねる。「あさに する」のあとに、特別な服をひとつ選べる。
  - 7つめ(カタカナ44字)に着くと、「ぜんぶ おぼえたね」のお祝い画面(`allClear`)が1度だけ出る。そのあともゲームは続く。
- **商店街のゴール(「お店が全部開く」はクリアではない):**
  - 商店街の一番右に「ゴールの門」(`drawGoal`)を置く。門の上に7つの灯りがあり、「まほうの みち」の旗を1つ進むごとに1つともる。次の灯りは、進み具合に応じて明るくなる。ツタは進むほど減る。7つめで、扉が開いて光があふれ、星が輝く。7つそろう前にタップすると、ともった灯りの数だけ音が鳴る。7つそろったあとにタップすると、魔女が門まで歩いて「まほうの おしろ」に入れる。
  - **まほうの おしろ(`castle`):** 12人のお客さんが並んで応援する広間。人形(今の服のまま)と魔女がいる。窓の外の空は、お店の窓と同じ時刻(朝・夕焼け・夜)で変わり、その中で花火が上がる(窓をタップするとそこに花火)。紙ふぶきが舞う。お客さんが、依頼画面のように吹き出しで「おめでとう!」などと言う(約3秒ごとに別の人)。人形は魔女の約6割の大きさ(足もとは魔女とそろえる)。人形・お客さんをタップすると跳ねて音が鳴る。左の出口(ボタン)で商店街へ戻る。
  - 商店街の上の7つの旗も、同じ進み(🚩×6と🌟)を示す。タップすると、門まで画面が流れる。
  - 門が見えていない間は、右端に小さな門のボタンが出る(押すと門まで流れる)。
  - お店の開き方は3段階(`tierOf`)。シャッター → 開店(直した物が1つ以上)→ にぎわい(その店の品物の35%以上を直した: ばんてい、音符が浮かぶ、窓が温かい色)→ 大繁盛(70%以上: 金のひさし、きらきら、音符が2つ)。お店の前に人は出さない(タップできそうに見えて紛らわしいため)。
  - 全部の文字を覚えて、お祝い画面が出たときに花火が上がる(`allClear`)。そのあと最初に商店街へ行くと、もう一度花火が上がる(`save.festSeen`)。クリア後(`save.cleared`)は、商店街にちょうちんが並び続ける。
- **なかよしのプレゼント:** 廃止しました(テンポが悪かったため)。支払いのときに浮かぶハートの演出だけが残っています。

## 12. 魔法の日記

お店の本をタップすると開きます。新しい記録があると、本の上で星が光ります。タブは4つで、絵で切り替えます。

| タブの絵 | 中身 |
|---|---|
| やかん | なおした もの: 直した物の図鑑。日付、ひらがなの感想(全部の物にある)、依頼したお客さんの顔とひとこと、「♪ きく」 |
| 星 | とくべつな こと: スタンプのごほうび、昔のプレゼント、お店の星が増えた日 |
| 三日月 | まいにちの きろく: 1日ごとのまとめ |
| 星の夜空 | ほしぞら: 文字の行ごとの星座。慣れた文字が光り、1行そろうと星座が完成して光る(文字そのものは出さない) |

ページは日付の順に並びます。

## 13. お店の飾り(自分のお店)

| 飾り | タップしたとき |
|---|---|
| ビン | 揺れて泡が出る |
| 本 | 日記が開く |
| ランプ | 明かりがついたり消えたりする |

どれも魔女がひとこと言います。背景になじむよう、少し小さく薄く描いています。

## 14. 音

- **効果音:** ポロン(8段階)、ファンファーレ、ブー、ガイドに近づいたときのキラッ(iPhone では鳴らさない)、ドアのベル
- **BGM:** 12曲。前もって作って埋め込んであります。

| 場面 | 曲 |
|---|---|
| お店(昼) | 昼の曲 |
| お店(夜)・1日のまとめ | 夜の曲 |
| 片付ける部屋・お店の中 | そのお店の種類の曲(9種類) |
| 自分の部屋 | 自分の部屋の曲 |
| パズル中 | 鳴らさない |

- **声:** 文字と言葉の読み上げ。前もって作った声(`VOICE_DATA`)があればそれを使い、なければ端末の読み上げを使います。
- 設定: タイトルで、BGM・効果音・声を別々にオン・オフできます。

## 15. チュートリアル・その他

- チュートリアル: 初めて「はじめる」を押したときに、絵つき4枚を出します(右上の「とばす」で飛ばせる)。
- はじめから: タイトル右下の薄い字。「はい」と入力したときだけ、全部消します(子どもの押し間違いを防ぐため)。
- 鍵: 何も直していない間は、買い物(看板とタイトルのボタン)に鍵が付きます。
